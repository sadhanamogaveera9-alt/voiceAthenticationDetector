# Voice Authenticity Detector

## Build 2036 Project

**Challenge:** Applied AI and Agentic Intelligence

### About
Voice Authenticity Detector is an experimental audio analysis prototype designed to support awareness of voice-cloning impersonation risks.

### Features
- Upload audio files
- Play uploaded audio
- Audio duration analysis
- RMS Energy analysis
- Zero Crossing Rate
- Spectral Centroid
- MFCC Variation
- Audio waveform visualization
- Safety recommendations

### Technologies Used
- Python
- Streamlit
- Librosa
- NumPy
- SoundFile

### How to Run
1. Install Python.
2. Install required libraries using `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.

### Limitation
This prototype analyzes audio signal characteristics. It is not a validated AI voice detection classifier.

### Future Scope
- Integrate a validated AI detection model.
- Improve audio analysis.
- Explore real-time analysis.
- Develop a mobile application.

### Project Purpose
To demonstrate an experimental audio analysis dashboard and promote awareness of voice impersonation risks.
